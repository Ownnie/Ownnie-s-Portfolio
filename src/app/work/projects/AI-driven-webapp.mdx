## Overview
This AI-driven innovation platform helps businesses streamline idea submission and evaluation by detecting duplicate proposals and automating workflow processes.

## Key Features
- **AI-Powered Duplicate Detection**: Uses Google's AI API to identify and remove redundant proposals.
- **Automated Workflow Management**: Enhances efficiency by automating approval processes.
- **User Dashboard**: Provides real-time insights on submissions and approvals.

## Technologies Used
- **Angular**: For building a dynamic and interactive UI.
- **Java Spring Boot**: Backend logic and API development.
- **Google AI API**: For intelligent text and content analysis.
- **Tailwind CSS**: For a modern, flexible, and responsive design.

## Challenges and Learnings
- **AI Accuracy**: Ensuring high precision in detecting duplicate submissions.
- **Performance Optimization**: Managing high-volume requests efficiently without delays.

## Outcome
- **30%** reduction in redundant proposals, improving workflow efficiency.
- Enhanced automation, reducing manual review times and increasing approval rates.
- Improved collaboration between innovation teams, ensuring faster decision-making.
