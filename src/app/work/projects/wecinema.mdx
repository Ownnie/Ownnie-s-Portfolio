## Overview
WeCinema is an innovative B2B platform that connects independent filmmakers with studios, enabling seamless transactions for film projects, scripts, and collaborations.

## Key Features
- **Content Marketplace**: A digital hub for script sales and production partnerships.
- **Secure Transactions**: Integrated payment and contract management system.
- **Project Discovery**: Advanced search and filtering to connect creators with relevant studios.

## Technologies Used
- **React.js**: Dynamic frontend framework for a responsive user experience.
- **Django**: Backend framework handling transactions and database management.
- **Hostinger**: Cloud hosting for optimal performance.
- **JavaScript**: For interactive components and smooth client-side functionalities.

## Challenges and Learnings
- **Security & Transactions**: Implementing secure payments and contract signing features.
- **User Onboarding**: Ensuring an intuitive interface for filmmakers and studios.

## Outcome
- Enabled **faster deal closures** for independent filmmakers and studios.
- Increased accessibility to industry professionals through a **centralized marketplace**.
- Improved monetization opportunities for content creators through a streamlined sales process.
